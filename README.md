# Lumina Launcher

Простой и быстрый лаунчер Minecraft. Поддерживает онлайн-вход и регистрацию через аккаунты Microsoft.

## Возможности
- Вход и регистрация через официальные онлайн-аккаунты Microsoft
- Поддержка всех версий: от Alpha до последних снапшотов
- Автоматическая установка Forge, Fabric, OptiFine
- Быстрый запуск и понятный интерфейс

## Поддерживаемые версии
- Alpha: a1.0.4 – a1.2.6
- Beta: b1.0 – b1.8.1
- Release: 1.0 – 1.21.x
- Snapshots: последние снапшоты
- Modloaders: Forge, Fabric, NeoForge, Quilt

## Установка
1. Скачай последнюю версию из Releases.
2. Запусти LuminaLauncher.exe.
3. Войди через аккаунт Microsoft.
4. Выбери версию и играй.
